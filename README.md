# 😊 AI Emoji Prediction System

A real-time facial emotion recognition application built using **Python**, **OpenCV**, and **Machine Learning**. The system detects a person's face from an image or webcam feed, predicts the facial emotion, and displays the corresponding emoji with a matching background.

## 🚀 Features

- Real-time face detection using OpenCV
- Facial emotion recognition
- Emoji prediction based on detected emotion
- Dynamic background changes for each emotion
- Image upload and webcam support
- Simple and interactive user interface

## 🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Machine Learning
- Streamlit

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/sannith86/emoji-prediction.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
